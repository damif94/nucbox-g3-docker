Política de privacidad — hermes

Última actualización: 24 de octubre de 2026.

hermes es un asistente personal privado, de uso exclusivo de su desarrollador (Damian Ferencz). No es un servicio público y no tiene otros usuarios.

Qué datos de Google se acceden

Con la autorización de su propietario, hermes lee —sin modificar nada— datos de la cuenta de Google del propio desarrollador: Gmail, Google Calendar, Google Drive, Google Docs y Google Sheets (permisos readonly).

Cómo se usan

Los datos se usan únicamente para responder pedidos del propietario (por ejemplo, resumir correos o consultar la agenda). No se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos propios.

Dónde se almacenan

El token de acceso se guarda en un servidor propio, en la red privada del desarrollador. Para generar respuestas, fragmentos del contenido consultado se envían a la API de Anthropic, sujeto a sus términos de privacidad.

Revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las APIs de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
